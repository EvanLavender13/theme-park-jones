# Exceptions

Anything that does not fit fields, flows, or encapsulation (principles 3 and 6) is listed here with the reason it cannot. An entry is a debt, not a permission: it names the code that bends the rule and why nothing cleaner works yet.

A growing list means a principle is wrong. When entries accumulate, raise it with Evan rather than adding another.

Each entry gives the location in code, the principle it bends, the reason, and what would remove it.
