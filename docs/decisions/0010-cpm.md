# 0010. CPM for dependency management

Status: Accepted, 2026-09-26

## Context

Dependencies must build identically under MSYS2 GCC and Linux GCC. vcpkg is not installed and supports MinGW only through community triplets.

## Decision

Dependencies are fetched and built from source with CPM.cmake, vendored at cmake/CPM.cmake. Each dependency is pinned to a release tarball. The presets set CPM_SOURCE_CACHE to .cpm-cache in the repository, so the Windows and Linux builds share downloads.

## Consequences

Dependencies are added as SYSTEM so their warnings and clang-tidy findings do not reach project code. A fresh configure downloads and builds SDL3, glslang, and Catch2, which takes a few minutes.
