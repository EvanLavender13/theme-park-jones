# Decision Records

One file per decision that is expensive to reverse, numbered in order: `NNNN-short-name.md`. A record states its status and date, the context that forced the decision, the decision itself, and its consequences.

Accepted records are not rewritten. To change a decision, write a new record that supersedes the old one and set the old record's status to "Superseded by NNNN". Changing a principle in docs/principles.md always goes through a record.
