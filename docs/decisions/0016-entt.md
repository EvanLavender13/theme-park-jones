# 0016. EnTT as the ECS

Status: Accepted, 2026-09-26

## Context

Decision 0002 calls for an ECS. A typical ECS lets any system query any component, which works against principle 6 (nothing reads another thing's internals).

## Decision

Use EnTT, pinned through CPM. Principle 6 is enforced through type visibility: an entity kind's internal components are declared in headers private to its module, so other modules cannot name them in a view. Only shared-medium components, such as field emitters and flow endpoints, are declared in public headers.

## Consequences

A mechanical check is needed so that a module's private headers are not included from outside it; it is added when the first entity kind lands. Iteration order over EnTT storage must not affect simulation results unless that order is itself deterministic.
