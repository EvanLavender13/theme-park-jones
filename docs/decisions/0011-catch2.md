# 0011. Catch2 v3 as the test framework

Status: Accepted, 2026-09-26

## Context

The principles call for property-style tests: determinism across seeds, conservation across random flow graphs, attribution sums matching field values.

## Decision

Catch2 v3. Its generators suit property-style tests, and benchmarking and matchers are built in.

## Consequences

Tests are discovered into CTest with catch_discover_tests, so ctest runs each test case individually.
