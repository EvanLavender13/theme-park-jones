# 0003. Building and the simulation substrate first, coasters later

Status: Accepted, 2026-09-26

## Context

The biggest gripe with existing games is manual placement of tiny pieces, and every later system (shops, rides, guests) depends on the shared medium of fields and flows.

## Decision

Build the building tools and the simulation substrate first. Coasters come later.

## Consequences

The first milestone (docs/vision.md) is a boxes-and-tubes slice with terrain, paths, one shop, guests, one field overlay, and a placement preview. No coasters and no procedural building geometry in it.
