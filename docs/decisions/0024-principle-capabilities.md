# 0024. Capabilities may implement a principle

Status: Accepted, 2026-09-26

## Context

The capability naming rule from SteelJones allowed only a quality or a discipline, to keep out names with a finish line such as a feature or an object. The shared medium of fields and flows is neither: it is the implementation of principles 3 and 6. It never finishes either, because it deepens with every new kind of field, flow, and network.

## Decision

A capability may be named after a principle it implements, as well as a quality or a discipline. The test that it can hold a tenth milestone without the name feeling wrong still applies. A principle capability cites its principle, and its foundation criteria include the checks that back that principle.

## Consequences

shared-medium is a valid capability name. planning-capabilities and planning-overview state the widened rule.
